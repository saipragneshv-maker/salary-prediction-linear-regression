# Salary Prediction Using Linear Regression

## 📌 Project Overview

This project uses machine learning to predict annual salary based on years of work experience.

The project includes data exploration, visualization, and a linear regression model for salary prediction.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🔍 Project Workflow

1. Loaded the salary and experience dataset
2. Explored the dataset using Pandas
3. Checked data types, missing values, and duplicate records
4. Performed exploratory data analysis
5. Visualized the relationship between experience and salary
6. Split the data into training and testing sets
7. Trained a Linear Regression model
8. Generated salary predictions
9. Evaluated the model using MSE, MAE, RMSE, and R² score

## 🤖 Machine Learning Model

**Algorithm:** Linear Regression

**Input Feature:**
- Years of Experience

**Target:**
- Annual Salary

## 📊 Model Evaluation

The model was evaluated using:

- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
